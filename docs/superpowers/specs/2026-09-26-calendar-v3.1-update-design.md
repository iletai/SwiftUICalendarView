## 1. Library Body — Year/Week/Single Rendering

### 1.1 CalendarView.body Switch on viewMode

Current body always renders month grid. Update to read `viewMode` environment:

```swift
switch viewMode {
case .month:
    // existing LazyVGrid 7-col month grid (unchanged)
case .year(let displayMode):
    // ScrollView > LazyVGrid 3-col, each cell = mini-month
    // .full: show weekday symbols + day numbers
    // .compact: day numbers only, smaller font
case .week:
    // Single HStack/LazyVGrid of 7 cells for the week containing displayDate
case .single:
    // Single large day cell with event detail list
}
```

### 1.2 FastCalendarEngine.computeWeekMatrix

New method returning 7 `CalendarDayState` cells for the week containing a given date:

```swift
public static func computeWeekMatrix(
    for date: Date,
    calendar: Calendar,
    todayDate: Date = Date(),
    selectedKeySet: Set<Int> = [],
    rangeBounds: (startKey: Int?, endKey: Int?) = (nil, nil),
    disabledRule: (@Sendable (Date) -> Bool)? = nil,
    eventsMap: [Int: [CalendarEvent]] = [:]
) -> [CalendarDayState]
```

### 1.3 Year View Details

- `ScrollView` containing `LazyVGrid(columns: 3)` of 12 mini-months
- Each mini-month calls `computeMonthMatrix` and renders compact 7-col grid
- `ScrollViewReader` + `.scrollTo(currentMonthKey)` on appear
- Year title in header, prev/next navigate by year
- Mini-month title tappable → switches to `.month` mode for that month

### 1.4 Week View Details

- 7-cell `HStack` or `LazyVGrid(columns: 7)`
- Header shows week range (e.g. "Sep 22 – 28, 2026")
- Prev/next navigate by week via `calendar.date(byAdding: .weekOfYear, value: ±1)`

### 1.5 Navigation Changes

- `changeMonth(by:)` → generalized `navigate(by:)` that respects viewMode:
  - `.month` → ±1 month
  - `.year` → ±1 year
  - `.week` → ±1 week
  - `.single` → ±1 day

## 3. Style & Animation

### 3.1 Card Style (Example App)

- Replace `Color(.secondarySystemBackground)` → `.ultraThinMaterial`
- Rounded corners 16pt with subtle shadow
- Each tab applies `.tint(accentColor)` at NavigationStack level

### 3.2 Animations (Library + Example)

**In Library (CalendarView.swift):**
1. Month transition: wrap `displayDate` changes in `withAnimation(.spring(response: 0.35, dampingFraction: 0.8))`
2. Mode switch: `.animation(.spring(response: 0.4, dampingFraction: 0.85), value: viewMode)` on body

**In DefaultCalendarDayCell:**
3. Selection tap: subtle `.scaleEffect(state.isSelected ? 1.0 : 0.95)` with spring

**In Example Only:**
4. Year scroll: `ScrollViewReader` `.onAppear { proxy.scrollTo(currentMonthKey) }`

### 3.3 Selected/Today Visual Upgrade (DefaultCalendarDayCell)

- Selected: `LinearGradient` fill instead of flat color
- Today (unselected): accent ring with `.shadow(color: accent.opacity(0.3), radius: 4)`
- Range band: gradient opacity from 0.15 to 0.25
